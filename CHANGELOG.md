# Changelog

## 1.1.0 (build 12) — first public release

- Move/resize supported windows with configurable modifier and mouse bindings.
- Left/right snap, intentional maximize/restore and Escape cancellation; no top-edge auto-maximize.
- Quick Guide and local Gesture Practice; menu-bar controls, exclusions and optional Launch at Login.
- Monterey native pop-up controls and embedded legacy login helper; modern login implementation on macOS 13+.
- Universal arm64/x86_64, macOS 12+. Free, proprietary binary distribution; no subscription, account or paywall.
- Signed informational update feed; manual installation only. Not Apple notarized; Accessibility approval may need renewing after updates.
