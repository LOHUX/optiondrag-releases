# Install OptionDrag

OptionDrag 1.1.0 (build12) is universal for Apple Silicon and Intel and requires macOS12 Monterey or later. Accessibility permission is required to move and resize supported windows.

1. Download the [official DMG](https://github.com/LOHUX/optiondrag-releases/releases/download/v1.1.0/OptionDrag-1.1.0-universal.dmg). The [ZIP archive](https://github.com/LOHUX/optiondrag-releases/releases/download/v1.1.0/OptionDrag-1.1.0-universal.zip) is also available.
2. Open the DMG and drag OptionDrag into Applications. Open the installed copy, rather than running it from the disk image.
3. Review the macOS warning. This release is ad-hoc signed for bundle integrity, not Developer ID signed or Apple notarized. Only approve an official download you trust, using Open Anyway if macOS offers it. Follow [Apple’s security instructions](https://support.apple.com/en-us/102445). On Monterey use System Preferences → Security & Privacy → General; on newer macOS use System Settings → Privacy & Security.
4. If macOS reports a damaged file, malware or harm to your computer, stop and contact support. Do not bypass that warning or disable system protections. ZIP is another package, not a security bypass.
5. Open OptionDrag and choose Set Up Accessibility. Approve the installed application yourself in the system Accessibility list. No Screen Recording or Full Disk Access permission is required.
6. Hold Option and drag left to move a supported window, right to resize, or double-click to maximize/restore. Quick Guide shows your current bindings.

[Visual Installation Guide](https://optiondrag.app/help/install/) · [Help](https://optiondrag.app/help/) · [Contact](mailto:contact@optiondrag.app)

Update checks open the official release page; automatic in-app installation is disabled. Updates may require Accessibility approval again. Downloading and using the app never requires payment.
